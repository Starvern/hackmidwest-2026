# Sapling branding

User-selected name: Sapling. Selected in the chat “Workshop Sapling logo concepts”:
original S Sprout symbol with option A's Michelangelus-inspired serif wordmark.
The lettering is generated concept artwork, not a licensed/typeset Michelangelus
font file. Assets were isolated from the selected concept via imagegen.

Project assets: `static/brand/sapling-logo.png` (horizontal transparent lockup),
`static/brand/sapling-symbol.png` (transparent square symbol).
Use the lockup with accessible alt text “Sapling”; decorative repeated symbols
use empty alt text with an accessible label on their parent link. On dark surfaces
place the black symbol on a light tile. The global favicon uses the symbol.

P1's page title/header/navigation/footer are updated. When integrating the newer
P3 page, retain these brand assets and changes, and apply Sapling to the intake
page's visible product name/title as well. Do not globally replace old provenance,
accepted contracts, fingerprints or historical documentation: these are evidence,
not user-facing branding. No financial/model behavior changes are intended.
